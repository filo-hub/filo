worker.js — Backend Security & Performance

⚙️ worker.js
Security Stored XSS via MIME parameter injection

Fixed isInlineType() to strip MIME parameters before checking. Previously, image/svg+xml; charset=utf-8 bypassed the SVG inline block, allowing script execution. Now normalizes to base type and blocks text/html, application/xml, text/xml.

Security Enhanced filename sanitization

Added backslash (\) and semicolon (;) stripping to sanitizeFilename() to prevent Content-Disposition header injection attacks.

Performance HEAD and Range requests optimized

Switched to BUCKET.head() for HEAD and Range requests instead of get(). Avoids downloading full object bodies when only metadata is needed, significantly reducing bandwidth and latency for large files.

Correctness Range request RFC 9110 compliance

Fixed Range clamping: end >= obj.size now clamps to obj.size - 1 instead of rejecting as 416. Added validation for zero-length suffix ranges. Handles over-long ranges correctly per RFC 9110.

Enhancement Expanded MIME type coverage

Added 20+ MIME types to the map: AVIF, BMP, ICO, TIFF, WebM, MOV, MKV, FLAC, AAC, OGG, Markdown, YAML, fonts (WOFF, WOFF2, TTF, OTF), archives (TAR, GZ, 7Z, RAR).

Correctness Reconcile orphan detection

Implemented R2 orphan detection in reconcile(): now lists up to 50 objects in the bucket with no D1 row. Reports them without deleting (objects are data, rows are metadata). Uses head() for row validation instead of get().

Correctness API rename category clearing

Fixed /api/rename: sending category: "" now correctly sets NULL (clears category). Omitting the field preserves the existing value. Previously used COALESCE(?, category) which prevented clearing.

Correctness MIME type normalization in guessContentType

Updated guessContentType() to strip MIME parameters from provided types before returning them, ensuring consistent type handling throughout the worker.

App.svelte — Frontend Resilience & UX

🎨 src/App.svelte
Enhancement Category sidebar persistence

Fixed category disappearance on filtered views by introducing allCats Set. Categories now accumulate across loads and persist when search/filter is active. Sorted alphabetically for consistency.

Correctness Resilient batch upload queue

Modified uploadAll() to remove successfully uploaded files from queue individually. Failed uploads stay in queue for retry. Prevents clearing entire queue on partial batch failure.

Enhancement Dropzone drag flicker fix

Fixed drag state flicker by checking e.currentTarget === e.target in ondragleave. Added stopPropagation() to prevent parent bubbling. Drag state now stable during file hover.

Enhancement Keyboard accessibility

Changed dropzone from <label> to <div role="button"> for semantic correctness. Added keyboard activation (Enter/Space), tabindex="0", focus ring (focus:ring-2), and aria-label.

Technical Details

Security Model

  • XSS Prevention: All script-capable MIME types (SVG, HTML, XML variants) forced to attachment via Content-Disposition
  • Type Normalization: MIME parameters stripped before policy checks to prevent bypass via type; charset=...
  • Header Injection: Filename sanitization removes semicolons and backslashes to prevent Content-Disposition injection
  • Inline Allowlist: Only images, video, audio, fonts, PDF, plain text, CSV, JSON, and Markdown render inline

Performance Optimizations

  • HEAD Optimization: Uses head() to fetch metadata without downloading object body (critical for large files)
  • Range Optimization: HEAD + Range requests fetch metadata first, then slice only requested bytes
  • Reconcile Efficiency: Switched from get() to head() for row validation, avoiding full object downloads during maintenance
  • Orphan Detection: Paginated R2 list with early exit at 50 orphans to prevent long-running reconcile operations

API Correctness

  • Category Handling: /api/rename now distinguishes between "clear" (empty string → NULL) and "preserve" (field omitted → unchanged)
  • Range Validation: Zero-length suffix ranges (bytes=-0) return 416, non-zero suffix ranges clamp correctly
  • Range Clamping: Over-long end positions clamp to size - 1 per RFC 9110 instead of rejecting
  • Orphan Policy: R2 objects without D1 rows are reported, never auto-deleted (objects are data, rows are metadata)
